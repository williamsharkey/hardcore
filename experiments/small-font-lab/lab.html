Sources, licenses, and rendering details

Text uses the original font bitmaps. These canvases display pixels exported by Hardcore’s actual C glyph renderer, without antialiasing. The “complete missing box shapes” option uses Hardcore’s existing box generator on the source font’s line centers; it never replaces a native box glyph. Other absent characters use the real Unifont fallback. The inspector identifies each case. All these faces are available in Hardcore’s Font settings.

At 1×, each bitmap pixel occupies one browser device pixel, even when Windows scaling or browser zoom changes. Move this window between displays to compare. The inspector is deliberately enlarged. Cell height includes line spacing; cap height measures the letters themselves.
