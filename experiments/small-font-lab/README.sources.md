# Small bitmap font sources

These are native bitmap cuts for the small-font comparison, acquired on
2026-10-15. All eleven cuts are included in Hardcore's production font menu;
the comparison and normal builds share canonical source files under `font/`.
Dimensions are **device-pixel cell width × cell height**, rather
than point size or the height of the capital letters. All fonts retain their
original glyph designs. No outline rasterization or image downscaling was used.

`candidates.json` records the exact BDF, original source/download URL, license,
SHA-256 of the **uncompressed** BDF, SHA-256 of its license, baseline ascent,
and measured coverage. Paths are relative to the repository root. Gzip wrappers
use timestamp zero. `stem_px` is the inspected vertical stem width in ordinary
`I`, `H`, and `n`; it does not imply that intersections, diagonals, serifs, or
every glyph use only one pixel. `cap_height` is the number of occupied rows of
`H`. Counts reflect glyphs admitted by Hardcore's production BDF reader.

| --- | ---: | ---: | ---: | ---: |
| Terminus 8×16 | 1 px | 10 px | 120 | 30 |
| UW ttyp0 9×17 | 1 px | 11 px | 128 | 32 |

| UW ttyp0 9×18 | 1 px | 11 px | 128 | 32 |

The 17–20 px shortlist is Terminus 18/20, UW ttyp0 17/18, X11 Fixed 18,
and Tamzen 20. Tamzen has attractive thin letters but requires fallback for
every Unicode box/block character. An honest comparison must identify those
fallback glyphs. Fixed 20 is included as a heavier control, not a hairline
recommendation. No synthetic 19 px cut is presented as an original font.

## Terminus 4.49.1

- [Author's project page](https://terminus-font.sourceforge.net/)
- [Original release archive](https://downloads.sourceforge.net/project/terminus-font/terminus-font-4.49/terminus-font-4.49.1.tar.gz)
- Archive SHA-256: `d961c1b781627bf417f9b340693d64fc219e0113ad3a3af1a3424c7aa373ef79`.
- Files: `ter-u16n.bdf`, `ter-u18n.bdf`, `ter-u20n.bdf`, `ter-u22n.bdf`,
  `ter-u24n.bdf`, compressed without changing their contents.
- License: SIL Open Font License 1.1, preserved in `font/terminus/OFL.TXT`.

These are the normal-weight Unicode cuts. Their ordinary light lines,
corners, heavy lines, double lines, and rounded corners are native. Eight
dashed box characters are absent. Production Hardcore fills these gaps for
all five cuts; the demo distinguishes original glyphs and generated or
fallback behavior. The author's notes rate the 22 px cut below the others,
so it is included as an intermediate size to inspect, not a preferred cut.

## UW ttyp0 2.1

- [Author's project page](https://people.mpi-inf.mpg.de/~uwe/misc/uw-ttyp0/)
- [Original release archive](https://people.mpi-inf.mpg.de/~uwe/misc/uw-ttyp0/uw-ttyp0-2.1.tar.gz)
- Archive SHA-256: `99506dd8794e1a5d5cd5811e6c1e55eeef989f8c3501fdb9265bda972aba1630`.
- License: ttyp0 License, preserved with the archive's auxiliary-tool MIT
  notice in `font/uw-ttyp0/LICENSE`.

The archive's `bdf/t0-17.bdf` and `bdf/t0-18.bdf` are **intermediate source
data, not directly usable Unicode fonts**. Their encoding numbers must not
be mistaken for Unicode code points. The 17 px file is a native-size overlay
on the 18 px font. Both original files are retained in `font/uw-ttyp0/` with `-source` in
their names for inspection, but only `-uni` files appear in `candidates.json`.

The usable BDFs were generated by the unmodified upstream rules and default
`VARIANTS.dat`, inside the unpacked 2.1 archive, without installing anything:

```sh
make -f Makefile.in genbdf/t0-17-uni.bdf genbdf/t0-18-uni.bdf
```

This invokes upstream `mkshallow`/`bdfmangle` to assemble the author's cuts
and assign Unicode encodings. It does not resample their pixels. The output
files are stored in `font/uw-ttyp0/` as `t0-17-uni.bdf.gz` and `t0-18-uni.bdf.gz`.

The default 17 and 18 px cuts have the same Latin letter bodies and differ
in cell leading. Both have complete Unicode box/block coverage. The license
permits redistribution and embedding, and requires a different font name if
glyph designs are modified or additional glyphs are added. These BDF designs
are unmodified; any renderer fallback should be identified separately.

## Tamzen 1.11.6

- [Maintainer's repository](https://github.com/sunaku/tamzen-font)
- [Pinned 8×16 BDF](https://raw.githubusercontent.com/sunaku/tamzen-font/Tamzen-1.11.6/bdf/Tamzen8x16r.bdf)
- [Pinned 10×20 BDF](https://raw.githubusercontent.com/sunaku/tamzen-font/Tamzen-1.11.6/bdf/Tamzen10x20r.bdf)
- [Pinned license](https://raw.githubusercontent.com/sunaku/tamzen-font/Tamzen-1.11.6/LICENSE),
  preserved in `font/tamzen/LICENSE`.

These normal-weight Latin cuts are a distinct thin-stroke alternative. Their
native Unicode box/block coverage is zero. At 20 px the cap body is only 10 px,
so it appears smaller and more widely spaced vertically than Terminus 20.
The current release does not provide an 8×17 cut; UW ttyp0 supplies the native
17 px comparison instead.

## X11 Misc Fixed

- [Maintainer's Unicode font page](https://www.cl.cam.ac.uk/~mgk25/ucs-fonts.html)
- [Original font archive](https://www.cl.cam.ac.uk/~mgk25/download/ucs-fonts.tar.gz)
- Archive SHA-256: `702fd1cdef9123e1871622a897727977c0933a420c50c94198f5bb22de8f0f8a`.
- Original files `9x18.bdf` and `10x20.bdf`, compressed unchanged.
- The public-domain notice is in each BDF and repeated in
  `font/misc-fixed/COPYING`.

The 9×18 cut combines thin letters with complete box/block coverage. The
10×20 cut uses two-pixel letter stems despite its one-pixel light boxes, so
is deliberately labeled a heavier control. The archive URL is unversioned;
the recorded archive and per-BDF hashes identify the exact retrieved data.
